# Contributing to Jannat-e-Kashmir Travel Packages Compose

Thank you for your interest in contributing to the **Jannat-e-Kashmir Travel Packages Compose** multi-tier application project!

## 🛠️ Contribution Workflow

1. **Fork the Repository**:
   Click the **Fork** button on GitHub.

2. **Clone your Fork**:
   ```bash
   git clone https://github.com/<your-username>/travel-app-compose.git
   cd travel-app-compose
   ```

3. **Configure Local Environment**:
   ```bash
   cp .env.example .env
   docker compose up -d --build
   ```

4. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/improvement
   ```

5. **Commit and Push**:
   ```bash
   git add .
   git commit -m "feat: enhance travel booking validation"
   git push origin feature/improvement
   ```

6. **Submit a Pull Request**:
   Open a Pull Request describing your changes and verification steps.
